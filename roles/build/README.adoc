= Ansible Role - nickhardiman.vm_satellite.build

Build a VM to host Satellite.

The latest version of Satellite does not run on the latest version of RHEL.
(Mar 2026, Satellite 6.18 runs on RHEL 9)
For OS requirements, see 
https://docs.redhat.com/en/documentation/red_hat_satellite/6.18/html-single/installing_satellite_server_in_a_connected_network_environment/index#configuring-repositories_satellite
